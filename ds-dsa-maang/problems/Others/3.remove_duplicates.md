Problem: Remove Duplicates from a Sorted Array

You are given a sorted integer array nums in non-decreasing order. Because the array is sorted, duplicate elements may appear next to each other.

Your task is to remove the duplicate elements in-place such that each unique element appears only once. The relative order of the elements must remain the same.

After removing duplicates, return the number of unique elements k in the array.

The first k elements of nums should contain the unique elements in the same order they originally appeared. The remaining elements of the array beyond the first k positions do not matter.

⸻

Function Signature

def removeDuplicates(nums: List[int]) -> int:


⸻

Input
	•	An integer array nums
	•	The array is sorted in non-decreasing order

⸻

Output
	•	Return an integer k representing the number of unique elements in the array.
	•	Modify the array in-place so that the first k elements contain the unique values.

⸻

Example 1

Input:

nums = [1,1,2]

Output:

k = 2
nums = [1,2,_]

Explanation:
The unique elements are 1 and 2, so the function returns 2.

⸻

Example 2

Input:

nums = [0,0,1,1,1,2,2,3,3,4]

Output:

k = 5
nums = [0,1,2,3,4,_,_,_,_,_]

Explanation:
The unique elements are 0,1,2,3,4.

⸻

Constraints
	•	1 ≤ nums.length ≤ 3 * 10⁴
	•	-100 ≤ nums[i] ≤ 100
	•	nums is sorted in non-decreasing order
