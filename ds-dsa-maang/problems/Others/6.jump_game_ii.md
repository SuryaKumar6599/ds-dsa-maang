## Why This Problem?

Jump Game is a classic interview problem that introduces one of the most important Greedy patterns.

It teaches you how to:

- Think greedily instead of exploring all possible paths.
- Maintain the farthest reachable position.
- Optimize from exponential solutions to O(n).

## Problem Statement

Given an integer array `nums`, where each element represents your maximum jump length from that position, determine whether you can reach the last index starting from the first index.

### Example 1

```python
nums = [2,3,1,1,4]
```

Output:

```python
True
```

Explanation:

```text
0 -> 1 -> 4
```

The last index can be reached.

### Example 2

```python
nums = [3,2,1,0,4]
```

Output:

```python
False
```

Explanation:

```text
You get stuck at index 3.
```

---

## Approaches

### 1. Brute Force (Recursive)

At every index:

- Try all possible jumps.
- Recursively check whether any path reaches the end.

**Time Complexity:** O(2ⁿ)

---

### 2. Dynamic Programming (Memoization)

Store previously computed states to avoid repeated work.

**Time Complexity:** O(n²)

---

### 3. Greedy (Optimal)

Maintain the farthest index reachable while traversing the array.

If the current index becomes greater than the farthest reachable position, the destination cannot be reached.

---

## Greedy Intuition

Instead of asking:

> "Which jump should I take?"

Ask:

> "What is the farthest position I can reach so far?"

If every position up to the current index is reachable, then only the maximum reachable position matters.

---

## Greedy Solution

```python
def canJump(nums):
    farthest = 0

    for i in range(len(nums)):
        if i > farthest:
            return False

        farthest = max(farthest, i + nums[i])

    return True
```

## Interview Insight

Most candidates initially think about:

- Backtracking
- DFS/BFS
- Dynamic Programming

The key observation is:

> If you can reach index `i`, the only information that matters is the farthest position reachable from any previously visited index.

This allows the problem to be solved using a single pass Greedy algorithm.
