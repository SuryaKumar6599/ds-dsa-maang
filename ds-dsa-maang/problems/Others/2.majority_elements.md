Problem: Find the Majority Element

You are given an integer array nums of size n. Your task is to find the majority element in the array.

The majority element is the element that appears more than ⌊n / 2⌋ times in the array.

It is guaranteed that the majority element always exists in the input array.

Return the majority element.

⸻

Example 1

Input: nums = [3,2,3]
Output: 3

Explanation:
3 appears 2 times, which is greater than ⌊3/2⌋ = 1.

⸻

Example 2

Input: nums = [2,2,1,1,1,2,2]
Output: 2

Explanation:
2 appears 4 times, which is greater than ⌊7/2⌋ = 3.

⸻

Constraints
	•	1 ≤ nums.length ≤ 5 * 10⁴
	•	-10⁹ ≤ nums[i] ≤ 10⁹
